### 🚗 CarInsurance – ASP.NET MVC Web Application

A full-stack insurance quote web application built with ASP.NET MVC and Entity Framework.

**Features:**
- Full CRUD functionality (Create, Read, Update, Delete)
- Automatic insurance quote calculator based on user inputs
- Admin view showing all quotes with client details
- Database persistence using SQL Server
- MVC architecture: Models, Views, Controllers

**Technologies:** ASP.NET MVC 5, Entity Framework 6, C#, Razor Views, SQL Server, Bootstrap

---

### ⏰ ServerTimeApp – ASP.NET Core Razor Pages App

A simple ASP.NET Core web application that displays the live server time in the browser.

**Features:**
- Displays real-time server date and time
- Built with Razor Pages and OnGet() handler
- Published to Azure App Service

**Technologies:** ASP.NET Core, Razor Pages, C#, Azure

---

### 🎓 StudentCodeFirst – Entity Framework Code First Console App

A console application that demonstrates Entity Framework Code First by creating and managing a Student database entirely from C# code.

**Features:**
- Code First database creation (no SQL required)
- Two related tables: Students and Courses
- Full CRUD operations (Add, Read, Update, Delete)
- LINQ queries for searching and filtering
- Database statistics (average GPA, highest/lowest, students per program)

**Technologies:** C# (.NET Framework), Entity Framework 6 (Code First), LINQ, SQL Server

## 📝 How to Use

1. Clone the repository: git clone https://github.com/zezozayed894/portfolio.git

2. For the **live portfolio website** visit:
https://zezozayed894.github.io/portfolio/

3. For **CarInsurance** and **StudentCodeFirst**:

   - Open NuGet Package Manager Console and run:

   - Press **CTRL + SHIFT + B** to build
   - Press **F5** to run

4. For **ServerTimeApp**:
   - Open in **Visual Studio 2022**
   - Press **F5** to run in the browser
